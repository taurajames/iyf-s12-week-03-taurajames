Day 5: Create Aliases for Common Commands

Objective

Practise creating aliases to make common terminal commands shorter and easier to use.

Aliases Created

  • ll for Get-ChildItem, to list files and folders.
  • c for code, to open VS Code.
  • grep for Select-String, to search file contents.

Commands Used

Set-Alias ll Get-ChildItem
Set-Alias c code
Set-Alias grep Select-String

ll
c .
grep -Path ".\daily-challenges\day-3.html" -Pattern "Project"

Get-Alias ll,c,grep

Verification

I tested the aliases and confirmed that all three pointed to their intended commands.

What I Learned

I learned how to create and use aliases in PowerShell. Aliases provide shorter names for commands, making terminal work quicker and easier.
