Day 3: Create a Project Boilerplate Script

Objective

Write a PowerShell script that automatically creates a basic project structure.

Script Created

I created a script named new-project.ps1 in the root directory of my repository.

Command Used

.\new-project.ps1 -ProjectName "week3-test-project"

Result

The script executed successfully and created the following structure:

week3-test-project/
├── daily-challenges/
└── README.md

What I Learned

I learned how to use PowerShell parameters, conditional statements, Test-Path, New-Item and Set-Content to automate project creation.
