Day 4: Practise grep to Search File Contents

Objective

Practise searching for specific words inside files using the terminal.

Commands Used

Select-String -Path ".\daily-challenges\day-3.html" -Pattern "Project"

Select-String -Path ".\daily-challenges\day-3.html" -Pattern "PowerShell"

Results

The first command found 7 matching lines containing "Project".

The second command found 2 matching lines containing "PowerShell".

What I Learned

I learned how to search file contents using Select-String in PowerShell. It provides functionality similar to grep in Linux.
