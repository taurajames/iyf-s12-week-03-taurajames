# Day 3: Create a Project Boilerplate Script

## Objective
Practise writing a PowerShell script that creates a basic project structure.

## Script
The script is named `new-project.ps1` and is located in the root directory of this repository.

## Command Used

.\new-project.ps1 -ProjectName "week3-test-project"

## Result
The script successfully created a project folder containing a daily-challenges folder and a README.md file.

## What I Learned
I learned how to use PowerShell scripts, parameters, conditional statements and New-Item to automate project setup.
