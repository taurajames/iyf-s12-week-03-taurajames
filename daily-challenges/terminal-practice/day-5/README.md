\# Day 5: Create Command Aliases



\## Objective

Practise creating shortcuts for common PowerShell commands.



\## Aliases Created



Set-Alias ll Get-ChildItem

Set-Alias c Clear-Host



\## How I Tested Them

The `ll` alias displayed the files and folders in the current directory.

The `c` alias cleared the PowerShell screen.



\## What I Learned

I learned how to use Set-Alias to create shortcuts for PowerShell commands. These aliases last only for the current PowerShell session unless they are added to the PowerShell profile.
