# Day 4: Search File Contents

## Objective
Practise searching for specific words inside files using the terminal.

## Command Used

Select-String -Path "README.md" -Pattern "project"

## Result
The command successfully found six lines containing the word "project" in my README.md file.

## What I Learned
I learned how to search for specific words inside files using Select-String in PowerShell. It performs a similar task to grep in Git Bash.
