# IYF Week 3 Pair Collaboration

## About the Project
This repository is part of the IYF WECAN Academy Season 12 Week 3 Developer Tools and Workflow assignment. It helps us practise Git and GitHub collaboration, including branches, pull requests, code reviews and merge-conflict resolution.

## Project Objectives
- Practise Git commands and feature branches.
- Create and merge changes through pull requests.
- Review a partner's work and provide feedback.
- Work together to resolve a merge conflict in `README.md`.
- Improve teamwork and version-control skills.

## Tools Used

- Git and GitHub
- Visual Studio Code
- PowerShell or Git Bash

## Collaboration Tasks
1. Create individual feature branches.
2. Make changes and open pull requests.
3. Review each other's work and provide feedback.
4. Resolve a merge conflict.
5. Merge approved changes into the main branch.
6. Check that both contributors appear under **Insights → Contributors**.
